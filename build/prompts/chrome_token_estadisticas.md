Necesito preparar en Meta Business Settings (Configuración del negocio) de Orchid un token NUEVO, solo para leer estadísticas de la página de Facebook y de Instagram. NO toques el token que ya existe, ni anuncios, campañas o pagos.

REGLA DE SEGURIDAD (muy importante)
- Cuando Meta muestre el token generado, NO lo copies, NO lo leas en voz alta, NO lo escribas en el chat ni lo pegues en ninguna parte. Detente en esa pantalla y avísame: Manuel lo copia a mano.
- No revoques ni regeneres ningún token existente.

PASO 1 · Ubicar el usuario de sistema
1. Abre https://business.facebook.com/settings y elige el negocio de Orchid.
2. Ve a Users → System users (Usuarios del sistema).
3. Dime qué usuarios de sistema hay y cuál tiene asignada la cuenta publicitaria act_1806647434085082. Usa ese.

PASO 2 · Asignar activos a ese usuario de sistema
1. Con el usuario seleccionado, pulsa "Assign assets" (Asignar activos).
2. Pages → "Orchid Pros" → activa como mínimo el permiso de ver estadísticas/insights ("View insights" o similar). No le des control total si no hace falta.
3. Instagram accounts → "orchidpros.staffing" → activa como mínimo el permiso de ver estadísticas/insights.
4. Guarda. Si alguna de las dos no aparece en la lista, detente y dime qué ves.

PASO 3 · Generar el token complementario
1. Con el mismo usuario de sistema, pulsa "Generate new token" (Generar token nuevo).
2. App: la misma que ya usa el token actual. Si hay varias, dime cuáles hay y espera.
3. Vencimiento: "Never" (Nunca).
4. Marca SOLO estos permisos:
   - pages_show_list
   - pages_read_engagement
   - read_insights
   - instagram_basic
   - instagram_manage_insights
   No marques ads_management, ads_read ni business_management.
5. Pulsa Generate (Generar). DETENTE en la pantalla del token y avísame. No lo copies.

AL TERMINAR, dime:
- Qué usuario de sistema y qué app usaste.
- Si la página y la cuenta de Instagram quedaron asignadas, y con qué permisos.
- Que el token está en pantalla esperando a que Manuel lo copie.
